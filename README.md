# 🧠 MemoryVerse AI

MemoryVerse AI is an AI-powered Digital Identity System that helps students organize, search, and interact with their academic and career documents using OCR, Knowledge Graphs, and Retrieval-Augmented Generation (RAG).

## 🚀 Live Demo

https://memoryverse-ai-f496.vercel.app

## 💻 GitHub Repository

https://github.com/subhamkewat/memoryverse-ai

## ✨ Features

- AI Document Ingestion
- OCR Metadata Extraction
- Digital Document Vault
- Knowledge Graph
- RAG Career Assistant
- AI Natural Search
- Career Analytics
- Resume ATS Audit
- Placement Forecast
- Skill Gap Analyzer
- AI Career Roadmap
